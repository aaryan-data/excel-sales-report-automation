# Excel Sales Report Automation

## Project Overview
Automated sales data analysis using Python (pandas).  
This project processes customer purchase history, calculates total sales per product, and generates a professional Excel report.

## Features
- Reads Excel sales data (`Customer_Purchase_History.xlsx`)
- Calculates total price for each purchase
- Groups data by **Product** and sums total sales
- Sorts products by total sales in descending order
- Exports a clean **Sales Summary** Excel file (`Sales_Summary.xlsx`)
- Fully automated and reusable script

## Technologies & Skills Used
- **Python**  
- **Pandas** (DataFrames, grouping, aggregation)  
- **Openpyxl** (Excel file handling)  
- **Data Cleaning & Analysis**  
- **Excel Automation**  
- **Report Generation**

## How to Run
1. Make sure Python is installed (>= 3.8)  
2. Install required libraries:
   ```bash
   pip install pandas openpyxl
3. Place Customer_Purchase_History.xlsx in the same folder as the script
4. Run the script: python Project1_Sales_Report.py
5. Check the output file Sales_Summary.xlsx
